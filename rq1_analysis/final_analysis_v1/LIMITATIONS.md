# Limitations

- **Missing outcomes.** There are 72 unknown outcomes, including 32 PRs with diff or metadata issues and 40 with insufficient file evidence. Missingness varies by repository and by the filename outcome. Similar marginal coverage across the three features cannot establish missingness at random. Raw rate bounds cover all binary assignments for these PRs. The adjusted assignment scenarios address selected possibilities.
- **Selection and confounding.** The source is the curated SpecMine sample, restricted to PRs with matched active specifications and non-test source changes. Near-complete verification improves coverage within that frame. Regression adjusts measured covariates and accounts for within-repository dependence. Tool and repository practices, PR complexity and unmeasured factors may still explain some associations. The analysis applies no sampling or verification weights because defensible weights for these targets are unavailable.
- **Timing and feature measurement.** The main exposures are from specification snapshots and may reflect edits after implementation. Historical heads establish contents at pinned heads. Earlier anchors cover only the detectable PR history. Heading detection can capture boilerplate, and the secondary testing-directive rule can miss differently phrased instructions. A feature indicator represents presence in any matched active specification.
- **Outcome measurement.** The outcome records whether an added eligible source file defines an executable automated test. It does not measure whether it ran or passed, how much behavior it covers, or whether quality improved. Direct AI source review and model-assisted classifications may still make semantic errors, even when hashes and citations pass validation. Earlier independent AI judgments are reference judgments. They provide no human accuracy benchmark.
- **Inference.** Bootstrap intervals are pointwise percentile intervals. Clustered Wald inference depends on the model and cluster distribution, and sparse exposure within individual tools limits precision. The secondary result is exploratory and changes under some missing-outcome assignments.
